El estudio

(02 — Estudio)

Cada sitio se diseña y se construye a mano. Sin plantillas, sin builders genéricos.

FORJA es un estudio de diseño y desarrollo web enfocado en negocios locales: restaurantes, comercios, profesionales independientes. El objetivo no es "una página", es más ventas: pedidos por WhatsApp, cobros con Mercado Pago, reservas que se completan solas. Trabajo con React, Next.js y JavaScript vanilla según lo que el sitio necesite, con base en Buenos Aires.

Stack
React · Next.js · JS
Framer Motion, Tailwind y vanilla cuando es lo más rápido.
Pagos & pedidos
WhatsApp + Mercado Pago
Integrados de fábrica, no como plugin agregado después.
Entrega
Días, no meses
Demo real antes de arrancar, para saber qué vas a recibir.
